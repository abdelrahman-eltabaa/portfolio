# 🌐 Personal Portfolio Website

A modern, responsive, and interactive portfolio website built to showcase my projects, technical skills, certifications, and professional journey as a **Software QA Engineer** and **Computer Engineering Graduate**.

## 🚀 Live Demo

**Portfolio Website:**
**https://abdelrahman-eltabaa.vercel.app**

---

## 📖 Overview

This portfolio serves as my personal website where recruiters, hiring managers, and fellow developers can explore my work, learn about my background, and easily connect with me.

The website was designed with a clean user interface, smooth animations, responsive layouts, and a modern user experience.

---

## ✨ Features

* Responsive design for Desktop, Tablet, and Mobile.
* Dark / Light mode.
* Modern and clean UI.
* Smooth scrolling and animations.
* Projects showcase.
* Skills section.
* Certificates section.
* Education timeline.
* Contact section.
* Social media integration.
* Fast loading performance.

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/abdo659/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
